**whatsNext**

Controle de Filmes e Série

Sobre o projeto

Aplicação web desenvolvida com o objetivo de permitir que usuários organizem e acompanhem seus filmes e séries por meio de uma Watchlist personalizada.

A aplicação utiliza a API do TMDB (The Movie Database) para consultar informações sobre filmes e séries, permitindo que cada usuário gerencie seus próprios conteúdos e acompanhe o que já assistiu ou pretende assistir.

Objetivos

- Desenvolver uma aplicação Full Stack utilizando React e Spring Boot.
- Integrar APIs externas para consulta de informações sobre entretenimento.
- Implementar autenticação de usuários utilizando Google Login.
- Permitir o gerenciamento de uma Watchlist pessoal.
- Aplicar conceitos de desenvolvimento REST API, persistência de dados e integração entre frontend e backend.

Funcionalidades implementadas

-  Autenticação de usuários com Google Login.
- Integração com a API do TMDB.
- Consulta de filmes e séries.
- Exibição de informações como título, sinopse, pôster e data de lançamento.
- Criação de Watchlist personalizada.
- Adição e remoção de conteúdos da Watchlist.
- Gerenciamento de status dos conteúdos:
  - Planejado: conteúdos que o usuário pretende assistir.
  - Assistido: conteúdos que o usuário já assistiu.
- Visualização e gerenciamento da lista pessoal.

Funcionalidades futuras

Integração com jogos por meio de uma API externa.
Sistema de avaliações pessoais para filmes, séries e jogos.
Sistema de comentários para todos os conteúdos.
Histórico de conteúdos consumidos.
Filtros e categorias para organização da Watchlist.




Tecnologias utilizadas

Frontend
- React: construção da interface e gerenciamento dos componentes.
- JavaScript: implementação da lógica e funcionalidades da aplicação.
- Tailwind CSS: estilização dos componentes.
- React Router: gerenciamento de rotas e navegação.

Backend
- Java: linguagem utilizada no desenvolvimento do backend.
- Spring Boot: construção da aplicação backend e disponibilização de endpoints REST.
- Spring Security: gerenciamento de autenticação e segurança.
- Google OAuth 2.0: autenticação utilizando contas Google.

APIs e serviços externos
- TMDB API: obtenção de informações sobre filmes e séries.
- Google Identity: integração com autenticação Google.

Banco de dados
- PostgreSQL: armazenamento e gerenciamento dos dados da aplicação.

Ferramentas
- Git e GitHub: versionamento e gerenciamento do código-fonte.
- Maven: gerenciamento de dependências e build do backend.

Conceitos aplicados

- Desenvolvimento Full Stack.
- Arquitetura cliente-servidor.
- Desenvolvimento e consumo de APIs REST.
- Integração com APIs externas.
- Autenticação e autorização de usuários.
- Operações CRUD.
- Persistência e relacionamento entre entidades.
- Componentização e reutilização de código.
- Separação de responsabilidades entre frontend e backend.

Objetivo educacional

Projeto desenvolvido para fins de estudo, com foco no aprimoramento de conhecimentos em desenvolvimento Full Stack, utilização de inteligência artificial para criação de roteiros e facilitar a organização, integração de tecnologias e construção de aplicações web.
